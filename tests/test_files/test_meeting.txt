二、项目进展汇报

王同学汇报了 Ezy-RAG 项目的最新进展：

- 已完成向量数据库的基本搭建（ChromaDB）
- 实现了文档的自动切片和向量化
- 支持 PDF、DOCX、TXT、MD 等多种格式
- MCP Server 已能正常提供查询服务

存在的问题：
- 数据库操作的原子性需要加强
- API 调用接口需要统一
- 指针管理存在混乱

三、技术方案讨论

针对数据库原子性问题，张教授建议采用影子集合策略：
- Shadow Collection Pattern
- Copy-on-Write 机制
- 指针切换保证原子性

李博士补充了 Rerank 的实现方案：
- 本地模式：使用 CrossEncoder 模型
- 云端模式：使用 Cohere 或 Jina 的 Rerank API
- 支持动态切换
