# 项目进展报告

## 项目概述

Ezy-RAG 是一个基于向量数据库的本地知识库系统，支持文档的切片、向量化、存储和检索。

## 当前进展

### 已完成的工作

1. **核心架构设计**
   - 采用 ChromaDB 作为向量数据库
   - 支持本地和云端 Embedding 模式
   - 实现了影子集合策略保证数据原子性

2. **功能实现**
   - 文档读取：支持 PDF、DOCX、TXT、MD 等格式
   - 文本切片：支持递归切片和平坦切片两种策略
   - 向量检索：基于余弦相似度的语义搜索
   - 重排序：支持本地和云端 Rerank 模式

3. **服务部署**
   - MCP Server：提供 HTTP API 供 opencode 调用
   - ChromaDB Server：向量数据库服务
   - Embedding Service：支持 LM Studio 本地部署

### 待优化事项

| 优先级 | 事项 | 状态 |

## 技术栈

- **语言**: Python 3.11+
- **向量数据库**: ChromaDB
- **Embedding**: Qwen3-Embedding / BGE-M3
- **Web框架**: FastAPI
- **包管理**: uv
